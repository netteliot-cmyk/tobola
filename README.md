# Tobola 🖤🏳️‍🌈

Ein frecher, stolzer Black-Metal-Hund zum Kümmern – als Web-App fürs iPhone.

**Spielen:** Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

## Was Tobola braucht
- 8× am Tag streicheln (mit dem Finger über ihn wischen, mind. 45 Min Abstand)
- 3 Mahlzeiten – aber nur Gemüse! Täglich 3000 Credits im Laden
- Abends baden: einschäumen und abduschen

Dazu: Musikanlage, Ballspielen, Zubehör, Schlafenszeit, Erfolge – und manchmal beißt er.

Zum Testen anderer Uhrzeiten: `?stunde=23` an die Adresse hängen.
